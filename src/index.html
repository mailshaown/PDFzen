Password protection

The open password is required to view the PDF. Editing permissions are advisory and may be ignored by some readers. PDFzen also appends an HMAC-SHA256 integrity seal and verifies it when the file is reopened; this is not a certificate-based digital signature. Passwords are kept in memory for this session only and are not saved in settings.
